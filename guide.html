화면 구성

  • 위쪽 줄: 설교 제목, 저장 상태, ↔ 성경 화면(성경 칸을 넓게 / 보통 / 접기), 설교 목록, 내보내기, 강단 보기, ⚙︎ 설정
  • 왼쪽 1/3 — 성경: 본문·대조 보기와 그 아래 연구 칸(원어 · 용례 · 주석 · 검색)
  • 오른쪽 2/3 — 설교: 제목·본문·날짜·예배·목표 시간, 중심 메시지, 마법사 단계, 원고 블록
  • 맨 아래: 원고 글자 수와 예상 설교 시간, 새 설교

아이패드 세로처럼 좁은 화면에서는 위쪽 성경 | 설교 단추로 두 화면을 오갑니다.

성경 읽기 · 번역 대조

  • 책과 장을 고르거나 ‹ › 단추(맥에서는 ← → 키)로 장을 넘깁니다.
  • 기본 번역본을 고르는 칸이 책 아래에 있습니다.
  • 대조를 누르면 절마다 여러 번역본이 차례로 나옵니다. 아래 동그란 단추로 함께 볼 번역본을 켜고 끕니다. 히브리어·헬라어 원문도 같은 방법으로 함께 봅니다.
  • 번역본 각주는 본문 아래 작은 글씨로 나옵니다.

절 고르기와 원고에 넣기

  1. 절 번호(금색 숫자)를 누르면 그 절이 골라지고 아래에 노란 줄이 나타납니다.
  2. 여러 절을 고르려면 범위 늘리기를 누르고 끝 절을 누릅니다. (맥: Shift를 누른 채 끝 절)
  3. 설교 본문으로: 오른쪽 위 ‘본문’ 칸에 지정됩니다. 그 칸을 누르면 언제든 본문으로 돌아갑니다.
  4. 설교에 넣기: 마지막으로 쓰던 원고 블록의 커서 자리에 「본문」(빌 4:6) 형태로 들어갑니다.

원어 · 용례 · 주석

원어

스트롱 코드가 달린 성경(.sdb)을 기본 번역본으로 두면 본문의 단어에 밑줄이 생깁니다. 단어를 누르면 원어(히브리어·헬라어), 음역, 스트롱 사전 뜻, KJV 번역, 어원, 그리고 그 성경이 이 원어를 어떤 우리말로 옮겼는지가 횟수와 함께 나옵니다. BibleHub·Blue Letter Bible·STEP Bible로 가는 연결도 있습니다. 연구 메모에 넣기로 오른쪽 메모 칸에 모아 둡니다.

공개 성경 묶음에는 스트롱 코드 성경이 없습니다. 대신 ‘대조’로 원문을 절마다 함께 보실 수 있습니다.

용례 · 관련 구절

누른 원어가 쓰인 구절을 모두 보여 주고, 해당 단어에 색을 칠합니다. 구절을 누르면 그 본문으로 갑니다.

주석

주석 파일(.cdb)을 넣으면, 고른 절이 속한 단락의 주석이 나옵니다. ‹ ›로 앞뒤 단락을 넘기고, 주석에서 문장을 드래그해 고른 뒤 선택한 글을 연구 메모에 넣기를 누릅니다.

단어 검색

  • 성경 칸 위의 🔍 또는 연구 칸의 검색 탭을 엽니다.
  • 여러 단어를 띄어 쓰면 모두 들어간 구절을 찾습니다. 예: 염려 기도
  • 찾을 번역본과 범위(성경 전체·구약·신약·지금 책)를 고릅니다. 한글 단어를 영어 성경에서 찾으면 자동으로 한글 성경에서 찾아 줍니다.
  • 결과 위에 책별로 많이 나오는 곳이 보이고, 결과 목록을 연구 메모에 넣기로 참조 목록을 모을 수 있습니다.

설교 마법사 — 종류 · 구조 · 순서

1. 설교 종류

강해, 주제, 절기, 새벽 말씀, 심방, 환우 심방, 이사·개업 심방, 장례(위로), 결혼 주례, 사랑방·구역, 구역 나눔, 제자훈련, 직분자, 교리 설교 가운데 고릅니다. 종류마다 어울리는 예배 자리·목표 시간·추천 구조가 채워집니다.

2. 설교 구조

구조흐름
강해식서론 → 배경과 문맥 → 본문 해설 1·2·3 → 중심 메시지 → 적용 → 결론 → 기도
3대지 · 2대지서론 → 대지들 → 결론 → 적용 → 기도
원 포인트여는 말씀 → 말씀의 핵심 → 적용과 권면 → 기도 (새벽·심방·구역)
연역적서론과 명제 → 근거 1·2 → 교리적 정리 → 적용 → 결론
귀납적질문 던지기 → 관찰 1·2·3 → 발견(중심 진리) → 적용 → 결론
스토리갈등 제시 → 심화 → 복음의 반전 → 복음의 경험 → 결말과 기대
문제 → 해결문제 제기 → 원인 진단 → 말씀의 해답 → 실천 → 결론
위로 구조위로와 공감 → 말씀의 약속 → 소망 → 남은 자의 삶 → 기도 (장례·환우)
축복 구조감사 → 말씀 → 축복의 약속 → 당부 → 축복기도 (이사·개업)
나눔식마음 열기 → 관찰 → 해석 → 적용 나눔 → 기도 제목 → 함께 기도 (구역·제자훈련)

이미 쓴 글이 있는 상태에서 구조를 바꿔도 지워지지 않습니다. 같은 이름의 블록으로 옮겨지고, 나머지는 뒤에 남습니다.

3. 순서 정하기

블록을 끌어서 옮기거나 ▲▼로 바꾸고, 이름을 바로 고칩니다. ✕로 빼고(글이 있으면 한 번 더 확인), 아래 단추로 서론·대지·예화·적용·나눔 질문·기도 같은 블록을 더합니다.

원고 쓰기

  • 중심 메시지: 이 설교가 말하려는 진리를 한 문장으로. 쓰는 내내 위에서 길잡이가 됩니다.
  • 연구 메모: 원어·주석·검색에서 모은 것과 본문 관찰을 적는 곳. 원고 분량에 들어가지 않습니다. ▾로 접을 수 있습니다.
  • 블록마다 안내 문구가 있고, 오른쪽에 그 블록의 글자 수가 보입니다.
  • 맨 아래 막대: 원고 글자 수와 예상 시간(⚙︎에서 정한 분당 글자 수 기준). 목표를 넘으면 주황·빨강으로 바뀌고 몇 자가 넘쳤는지 알려 줍니다.
  • 모든 글은 쓰는 대로 자동 저장됩니다.

AI 도우미

⚙︎ → AI 연결에서 키를 넣으면(키 받는 법) 블록마다 ✦ 도움이 생깁니다. 작성 단계 위쪽의 ✦ 전체 개요 제안은 모든 블록의 개요를 한 번에 제안합니다.

  • 초안 제안 · 문장 다듬기 · 분량 줄이기 · 예화 아이디어 · 적용 질문 · 본문 관찰 질문
  • AI의 답은 블록 아래 상자에 나오고, 커서 위치에 넣기 / 바꾸기 / 연구 메모로 중에서 고릅니다. 마음대로 원고를 바꾸지 않습니다.
  • AI에는 설교 정보, 본문, 연구 메모, 지금까지의 원고가 함께 전달됩니다.
  • ⚙︎의 AI 지침에서 신학 전통·말투 같은 기본 안내를 고칠 수 있습니다.

내보내기 · 강단 보기

  • 원고 전체 복사: 한글·워드·카카오톡에 붙여 넣기
  • 워드 파일(.doc) · 텍스트 파일(.txt) 내려받기
  • 백업 파일(모든 설교) 내려받기 / 백업 불러오기
  • Claude에게 부탁할 요청문 복사: AI 키 없이도 쓰시는 AI 앱에 붙여 넣을 수 있게, 본문·구조·메모·원고를 담은 요청문을 만듭니다
  • 강단 보기: 큰 글씨 원고. 가− 가+로 크기, 밤/낮으로 배경을 바꿉니다

설교 목록

위쪽 설교 목록에서 제목·본문·예배로 찾고, 누르면 열립니다. 복제는 지난 설교를 바탕으로 새 설교를 시작할 때, 삭제는 한 번 더 눌러 확인합니다. 같은 본문을 언제 어디서 설교했는지 확인하는 기록으로도 쓰입니다.

설정 (⚙︎)

  • 성경 자료: 파일 넣기·빼기 (자료 형식)
  • 본문 글꼴: 본명조 · 고운바탕 · 나눔명조 · 본고딕, 성경·원고 글자 크기
  • 설교 속도: 분당 글자 수(공백 제외, 보통 250~320자). 예상 시간 계산에 쓰입니다
  • 세례 / 침례 표기: 데이터의 ‘침례’를 원문대로 ‘세례’로 보여 줄지
  • 밤 모드, AI 연결, AI 지침

단축키 · 작은 팁

  • ← →: 이전·다음 장 (글을 쓰는 중이 아닐 때)
  • Shift + 절 번호: 범위 고르기
  • 맥 앱: ⌘+ / ⌘-로 화면 확대·축소, ⌃⌘F 전체 화면
  • ‘↔ 성경 화면’을 눌러 원고에 집중할 때는 성경 칸을 접어 두세요.
  • 지난 설교를 복제해서 같은 틀로 다음 주 설교를 시작하면 편합니다.
